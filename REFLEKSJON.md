Movie Explorer

I denne oppgaven har jeg laget en nettside som heter Movie Explorer. På nettsiden kan brukere se populære filmer, søke etter filmer og lese mer informasjon om hver film. Jeg brukte Next.js, TypeScript og CSS.

Jeg valgte film som tema fordi det er noe mange mennesker er interessert i. Jeg ønsket å lage en enkel nettside hvor brukere raskt kan finne informasjon om filmer.

Jeg valgte TMDB API fordi det inneholder mange filmer med bilder, beskrivelser og vurderinger. Jeg brukte Next.js App Router for å lage forskjellige sider og dynamiske ruter. For eksempel har hver film sin egen side med en URL som inneholder filmens ID.

Jeg laget også en egen MovieCard-komponent. Det gjorde det enklere å vise filmer på samme måte flere steder og holde koden ryddig.

Under arbeidet brukte jeg Git og GitHub. Jeg jobbet med forskjellige branches og lagret endringene med commits.

En utfordring var å hente informasjon fra TMDB API og vise den riktig på nettsiden. Jeg måtte forstå hvordan `fetch` fungerer, og hvordan jeg kunne bruke TypeScript til å beskrive dataene.

Jeg jobbet også med feilhåndtering. Hvis brukeren søker etter en film som ikke finnes, viser nettsiden en melding. Hvis en film-ID er ugyldig, vises en egen side med informasjon om at filmen ikke ble funnet.

En annen utfordring var å få filmplakatene til å se bra ut på forskjellige skjermstørrelser. Jeg løste dette ved å bruke CSS Grid og media queries.

Jeg har lært mer om Next.js, TypeScript og hvordan man bruker et eksternt API.

Jeg har fått bedre forståelse av dynamiske ruter, komponenter og hvordan man kan dele opp kode i mindre deler.

Jeg har også lært mer om responsivt design og tilgjengelighet. Jeg brukte blant annet tydelige lenker, etiketter på søkefeltet og synlig fokus ved tastaturnavigasjon.

Til slutt brukte jeg `npm run build` og `npm run lint` for å kontrollere at prosjektet fungerer og ikke har kodefeil.

Hvis jeg hadde hatt mer tid, ville jeg lagt til flere funksjoner. For eksempel kunne brukerne filtrert filmer etter sjanger eller lagret favorittfilmer.

Jeg ville også jobbet mer med design og testet nettsiden på flere forskjellige enheter.

Jeg er fornøyd med resultatet. Movie Explorer har de viktigste funksjonene jeg planla, og prosjektet har gitt meg nyttig erfaring med Next.js og TypeScript.

Jeg føler at jeg nå forstår bedre hvordan man bygger en nettside med informasjon fra et eksternt API.
